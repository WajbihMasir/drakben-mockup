DRAKBEN by the numbers

The engine: agent brain, ReAct reasoning loop, Stanford-style memory stream, tool registry and the intelligence pipeline — 104 modules across the core tree.

Reconnaissance, web and network exploitation, Active Directory, command-and-control, evasion and payload generation — each grouped by the pentest phase it belongs to.

The suite runs in CI on every push, alongside Ruff (35 rule groups), MyPy in strict mode and Bandit — with SonarCloud reporting zero open issues.

nmap, nikto, sqlmap, metasploit, nuclei and more — each registered with a type, an allowed phase and a risk level, so the agent can select and reason about them.

Capabilities

An instrument, not a wrapper around tools.

Every module reports structured output the agent can reason over — not raw console text it has to guess from.

01 · reasoning

ReAct reasoning loop

Thought → Action → Observation cycles with iteration tracking, a structured output parser, and a context compressor that keeps long engagements inside the token budget.

02 · memory

Persistent learning

A Stanford-style graph memory plus a ChromaDB vector store. It remembers what worked across sessions, penalises failing tools, and reuses proven strategies.

03 · recovery

Self-healing execution

Failure-context analysis and automatic replanning recover from failed steps without a human restart, and an anti-hallucination protocol validates model output against runtime reality.

04 · evasion

Adaptive WAF bypass

Fingerprints Cloudflare, AWS WAF, ModSecurity, Imperva and more, then mutates payloads with encoding chains and pattern learning that persists between runs.

05 · multi-llm

Provider-agnostic

OpenRouter (100+ models), local Ollama for private engagements, OpenAI, or a custom endpoint. A model router picks per task by complexity and budget.

06 · reporting

Executive-ready output

HTML, Markdown, JSON and PDF reports with CVSS-based risk scoring, evidence, proof-of-concept, and actionable remediation guidance.

quickstart
